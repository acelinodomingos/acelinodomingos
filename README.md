## 🎯 Sobre mim

Profissional com trajetória consolidada no **Instituto Nacional de Câncer (INCA)**, unindo expertise técnica em **infraestrutura hospitalar crítica** à aplicação prática de **Inteligência Artificial, automação e sistemas SCADA na área da saúde**.

Minha carreira é marcada pela capacidade de viabilizar recursos estratégicos, liderar modernizações complexas em ambientes de alta criticidade (onde a falha não é uma opção) e garantir conformidade rigorosa com as normas da ANVISA. Hoje, desenvolvo ferramentas de IA e simulação (Python, Streamlit, SCADA) aplicadas a diagnóstico e monitoramento de gases medicinais e sistemas criogênicos.

## 🚀 Projetos

### [AI-CryoDiag](https://github.com/acelinodomingos/AI-CryoDiag)
Sistema de IA para diagnóstico em armazenamento criogênico no SUS — telemetria e Machine Learning aplicados a tanques de gases medicinais.
**Stack:** Python · Streamlit · Machine Learning
**Demo ao vivo:** https://ai-cryodiag-gohujcmxnmxddww3v7vtkl.streamlit.app/

### [simulador-scada-tanques](https://github.com/acelinodomingos/simulador-scada-tanques)
Sistema SCADA de monitoramento de tanques de gases industriais (O₂, N₂, N₂O), com simulação de falhas, telemetria em tempo real e procedimentos de emergência.
**Stack:** HTML · CSS · JavaScript
**Demo ao vivo:** https://acelinodomingos.github.io/simulador-scada-tanques/
